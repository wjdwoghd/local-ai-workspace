# VS Code 형태의 개발 화면

> 0.1.1의 현재 동작과 실행 파일은 [통합 채팅·터미널 안내](unified-chat.md)를 참고하세요. 아래 내용은 이전 화면 구성 기록을 포함합니다.

후속 변경: Codex 탭을 **코딩**으로 바꾸고 DB 없는 API 서버 연결을 추가했다. 아래 초기 UI 검증과 미연결 설명 이후의 현재 동작·계정 상태는 [로컬 API 연결](local-api-connection.md)을 따른다. 별도 Codex 연결은 사용하지 않는다.

로컬 프로필을 선택하면 왼쪽 활동 표시줄 → 탐색기/소스 제어/설정 → 가운데 Monaco 편집기 → 하단 터미널 → 오른쪽 통합 챗 → 하단 상태 표시줄 순서로 표시한다. 기존 서버 모드에서는 **로컬 개발 환경** 화면에 같은 workbench를 사용한다. VS Code 확장 실행 환경이나 마켓플레이스를 포함하는 제품은 아니다.

## 사용

- 경계선을 마우스로 드래그해 탐색기/소스 제어 사이드바 너비, 챗 너비, 터미널 높이를 조절한다. 경계선에 키보드 초점을 주고 방향키로도 조절할 수 있다. 화면 크기에 따라 상한을 제한한다.
- 활동 표시줄에서 탐색기, 파일 검색, 소스 제어, 챗, 터미널, 설정을 연다. `Ctrl+B`는 사이드바, `Ctrl+백틱`은 터미널을 토글한다. 패널을 숨겨도 편집기·PTY는 유지하며 프로필/프로젝트를 종료하면 정리한다. 설정에서 레이아웃을 초기화한다. 크기 변경은 현재 화면에서 유지하며 앱 재시작 시 기본 크기로 돌아간다.
- 하단의 **셸 프로필**에서 PowerShell 또는 Git Bash를 선택한 뒤 **터미널 시작·재시작**을 누른다. 프로젝트마다 하나의 활성 터미널을 사용하며 재시작은 기존 프로세스 트리를 종료한다. 종료하지 않고 패널만 숨길 수도 있다.
- 터미널 시작 응답보다 먼저 도착한 출력·종료 이벤트는 임시 보관 후 해당 터미널 ID에만 적용한다. 시작 전 화면을 초기화해 초기 프롬프트와 ConPTY 제어 응답이 지워지지 않도록 한다. 시작 중에는 중복 시작·셸 변경을 차단하고 진행·실패 상태를 표시한다. `terminal.spec.ts`는 실제 PowerShell을 실행하고 시작 응답을 1.5초 지연해 초기 프롬프트, 명령 출력, 재시작 후 출력을 화면에서 확인한다.
- 2026-10-30 터미널 수정 검증: 타입 검사·데스크톱 빌드, 단위 테스트 64개, 터미널·작업공간 E2E 4개, unpacked Windows 앱의 지연 응답 회귀 테스트 통과. 포터블 파일의 `electron.launch` 직접 연결은 실패했으며, 별도 실행 후 루프백 CDP로 연결해 실제 PowerShell 프롬프트와 명령 출력을 확인했다. 기존 포터블 파일은 실행 중이라 덮어쓰지 않고 `Local-AI-Workspace-0.1.0-Portable-terminal-fix.exe`를 생성했으며, 이 PC의 `.tools/Start-Team-App.ps1`은 해당 파일을 우선 실행한다. 설치 파일도 갱신했으나 설치 마법사 재설치는 수행하지 않았다.
- Git Bash는 Git for Windows의 표준 시스템 설치(`Program Files/Git/bin/bash.exe`) 또는 현재 사용자 설치(`LocalAppData/Programs/Git/bin/bash.exe`)를 사용한다. 미설치 시 오류를 표시하며 임의 실행 파일이나 인자를 IPC로 받지 않는다. PowerShell은 Windows 기본 실행 파일을 사용한다. 터미널 환경 변수 허용 목록과 프로젝트 검사를 유지한다.

## 통합 챗 도구

| 도구 | 로컬 모드 | 인증된 서버 모드 |
| --- | --- | --- |
| 챗 | Astra 표시, 서버 미연결 안내 및 전송 차단 | 기존 ChatStatus의 실제 모델 ID로 Responses 스트리밍 요청 |
| 파일 검색 | 현재 프로젝트의 파일 이름·UTF-8 내용 검색, 결과에서 편집기 열기 | 로컬 프로젝트 또는 등록된 개인·허용 팀 문서 검색. 개인 문서 선택·등록, 문서 출처 확인 |
| 웹 검색 | 서버 미연결 안내 및 전송 차단 | 기존 서버의 webSearch 옵션, 실제 반환 출처 표시 |
| Codex | 기존 Ask/Edit/Agent, 열린 파일 로컬 검사·승인 UI | 동일한 기존 에이전트. 실제 Codex 연결·명령 격리 선행 조건은 여전히 미충족 |

서버 챗에서 **내 문서·팀 문서를 답변에 사용**을 선택할 수 있다. 로컬 프로젝트 파일 검색 결과는 자동으로 AI에 전송하지 않는다. 서버 모드는 등록된 문서를 기존 권한 검사로 검색하며 선택한 업로드만 서버에 저장한다. 새 챗 세션은 기존 서버 대화 API로 저장한다. 프로젝트/프로필/계정이 바뀌면 화면의 챗 상태와 검색 결과를 초기화한다. API 키를 데스크톱에 추가하지 않는다. Oracle이나 인증 서버를 로컬 모드에서 시작하지 않는다.

로컬 검색은 기존 workspace ID·인증·프로필 범위 검사와 경로 검증을 거친다. 숨김·빌드·비밀 이름 파일, junction/symlink·하드 링크, 바이너리/비 UTF-8, 256 KiB 초과 파일은 검색하지 않는다. 검색어 최대 256자, 파일 500개/누적 10 MiB/디렉터리 항목 5,000개/깊이 20/약 3초/결과 100개 한도를 적용하고 한도 도달 시 부분 결과로 표시한다. 단어 포함 기준으로 검색하며 PDF·Office 원문 검색은 서버에 등록한 문서 검색에서 지원한다.

## 아이콘과 참고 문서

공식 [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme)의 MIT 아이콘 일부를 확장자·대표 파일명에 매핑한다. TypeScript/React/JavaScript/JSON/HTML/CSS/Python/Java/C#/C/C++/Go/Rust/SQL/YAML/Markdown/PowerShell/Shell/이미지/PDF/압축 등의 파일과 폴더를 구분하고 알 수 없는 확장자는 기본 문서 아이콘을 사용한다. 전체 VS Code 확장의 모든 파일·폴더 규칙을 이식하지 않는다. 출처 커밋과 원본 라이선스는 `apps/desktop/src/renderer/assets/material`에 보관하며 앱 설정에서도 라이선스 전문을 확인할 수 있다.

셸 프로필 배치는 [VS Code 공식 Terminal Profiles](https://code.visualstudio.com/docs/terminal/profiles)를 참고했다. 표준 영역 구성은 [VS Code User Interface](https://code.visualstudio.com/docs/getstarted/userinterface)를 참고한다. API·인증은 기존 서버/승인 경로를 그대로 사용한다.

## 검증

추가 단위 테스트는 실제 프로젝트에서 한글 파일명·내용 검색, 비밀 파일/빌드/링크/바이너리 제외, 오래된 workspace 요청 거부, 결과 수 제한과 임의 셸·인자 거부를 검증한다. UI 테스트는 실제 Electron에서 세 경계선 마우스 조절, 탐색기/탭 아이콘, 로컬 검색·파일 열기, PowerShell·Git Bash의 실제 ConPTY 명령 결과, 패널 토글, 미연결 도구 표시를 확인한다. 서버 도구는 격리된 테스트 서버로 문서 업로드·검색·웹 응답·문서/웹 출처·계정 전환 시 초기화를 검증한다. 실제 OpenAI/Codex 계정 호출을 수행했다는 의미는 아니다.

2026-10-30 Windows 검증 결과:

- `pnpm typecheck`, 서버·데스크톱 `pnpm build`, `git diff --check` 통과.
- 단위 테스트 99개 통과(서버 37개, 데스크톱 62개).
- 전체 E2E 실행에서 12개 통과, EXE 환경 변수가 필요한 2개는 건너뜀. 이후 최종 패키지 경로를 지정하여 프로필·패키지·포터블·workbench 5개를 실행해 모두 통과함. 전체 14개 테스트를 각각 검증했다.
- 최종 unpacked 앱에서 실제 PowerShell/Git Bash, 마우스 크기 조절, 로컬 검색·아이콘, 라이트/다크 및 720×600 창, 프로필 재시작·분리 확인.
- Windows 설치형과 포터블 EXE 갱신. 설치 마법사 재설치는 수행하지 않았으며 코드 서명 인증서는 미설정.
- asar에 최종 main 코드·Material Icon Theme MIT 고지 포함, `.env`·실제 팀원 명단·Oracle 개인 설정 미포함 확인.
- 이번 UI 변경은 커밋·push하지 않았으며 기존 미커밋 변경을 보존함.
