# 로컬 작업 공간 검증 — 2026-10-30

Windows에서 DB 없이 실행하는 로컬 프로필 모드와 기존 서버 모드의 회귀를 검증했다. 서버 모드 E2E는 격리된 테스트 서버를 사용하며 실제 Oracle이나 OpenAI에 접속하지 않는다.

| `git diff --check` | 통과 |

로컬 프로필 단위 테스트는 테마·Git 기록의 분리와 재실행 복원, 다른 프로필 폴더 및 중복/상하위 프로젝트 연결 거부, 이전 세션 요청 거부, 명단 최초 가져오기, 손상 JSON 보존 및 junction 거부를 검증한다.

로컬 E2E는 임시 사용자 데이터 폴더와 가상 팀원 두 명을 사용했다. 강제 로컬 모드에 서버 URL을 함께 제공하고 수신 횟수를 측정해 **서버 요청 0회**를 확인했다. 개인 파일 보존, 실제 Git 스테이징과 승인·개인 기록, 편집 중 프로필 전환 취소/폐기, 다른 프로필의 폴더 선택 거부, 이전 workspace ID 거부, 재시작 후 개인 테마·기록·폴더 복원을 확인했다. 초기 테스트 종료에서 창 강제 파괴와 자동 종료가 경합해 시간 초과가 발생했다. 정리 시 프로필을 먼저 해제하고 Playwright의 정상 종료만 사용하도록 수정한 뒤 전체 E2E를 재실행해 통과했다.

기존 Git 단위 테스트는 임시 저장소에서 status/branch/diff, 선택 파일 stage/unstage/commit, 승인 만료·거절, 비밀 파일 차단, 실제 충돌 보존, 로컬 원격 저장소 push/pull과 네트워크·권한 오류 보존을 검증한다. GitHub 응답과 인증 오류는 모의 CLI를 사용하며 이번 로컬 모드 변경에서 실제 GitHub push·PR을 수행하지 않았다.

이 PC에서 앱용 인증 서버와 TLS 프록시를 종료하고 앱용 PDB `LOCALAI_TEAM`을 닫았다. 기존 프로젝트 PDB `FREEPDB1`은 READ WRITE 상태를 유지했다. DB 파일이나 계정은 삭제하지 않았다. 로컬 앱에는 Oracle 설정이 필요하지 않다.

설치형 EXE와 포터블 EXE를 갱신했고 포터블과 unpacked 앱을 실제 실행했다. Windows 설치 마법사 재설치·코드 서명 검증과 서로 다른 PC 10대 실사용은 수행하지 않았다. 실제 AI·팀 공유·서버 사용량은 로컬 모드 제공 범위에 포함되지 않는다. 같은 Windows 계정의 터미널·탐색기에 대한 OS 차원 격리는 제공하지 않는다.
